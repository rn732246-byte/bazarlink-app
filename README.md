# বাজারলিংক — রিয়েল অ্যাপ (ওয়েব + মোবাইল + ডাটাবেস)

এই প্রজেক্টে এখন একটা আসল ব্যাকএন্ড আছে (Firebase)। মানে —
পণ্য যোগ করলে, অর্ডার করলে, প্রোফাইল সেভ করলে — সব ডেটা স্থায়ীভাবে
জমা থাকবে এবং **পাইকারি ও দোকানদার একে অপরের সাথে আসলেই কেনাবেচা
করতে পারবে** (একজন পণ্য যোগ করলে সাথে সাথে অন্যজনের স্ক্রিনে দেখা যাবে)।

---

## ১. Firebase প্রজেক্ট বানানো (একবারই লাগবে)

1. [console.firebase.google.com](https://console.firebase.google.com)-এ যান, Google অ্যাকাউন্ট দিয়ে লগইন করুন
2. **Add project** চেপে একটা প্রজেক্ট বানান (যেকোনো নাম দিন, যেমন `bazarlink`)
3. বাম পাশের মেনু থেকে **Build → Authentication** → **Get started** →
   **Sign-in method** ট্যাবে গিয়ে **Phone** চালু (enable) করুন
4. ⚠️ **ফোন নম্বর দিয়ে OTP পাঠাতে Firebase-এর "Blaze" (pay-as-you-go)
   প্ল্যান লাগে।** প্রজেক্ট সেটিংসের নিচে **Usage and billing**-এ গিয়ে
   Blaze-এ আপগ্রেড করুন — একটা কার্ড যুক্ত করতে হবে, কিন্তু মাসে
   কয়েক হাজার OTP পর্যন্ত ফ্রি কোটার মধ্যেই থাকে, তাই সাধারণত বিল
   আসে না।
5. বাম পাশের মেনু থেকে **Build → Firestore Database** → **Create database**
   → যেকোনো লোকেশন বেছে **Start in production mode** দিয়ে তৈরি করুন
6. Firestore-এর **Rules** ট্যাবে গিয়ে এই প্রজেক্টের `firestore.rules`
   ফাইলের পুরো কনটেন্ট কপি-পেস্ট করে **Publish** করুন
7. **Authentication → Settings → Authorized domains**-এ গিয়ে যেখানে
   অ্যাপ হোস্ট হবে সেই ডোমেইন যোগ করুন (লোকালি টেস্ট করতে `localhost`
   এমনিতেই যোগ করা থাকে; Vercel/Netlify-তে ডিপ্লয় করলে সেই ডোমেইনও
   যোগ করতে হবে)
8. **Project settings** (⚙️ আইকন) → নিচে **Your apps** → `</>` (Web) আইকনে
   ক্লিক করে একটা ওয়েব অ্যাপ যোগ করুন → যে কনফিগ কোড দেখাবে সেখান থেকে
   মানগুলো কপি করুন

## ২. আপনার কম্পিউটারে সেটআপ

```bash
npm install
```

তারপর `.env.example` ফাইলটার একটা কপি বানিয়ে নাম দিন `.env`, এবং
Firebase থেকে কপি করা মানগুলো বসান:

```bash
cp .env.example .env
```

`.env` ফাইল খুলে পূরণ করুন:
```
VITE_FIREBASE_API_KEY=আপনার-key
VITE_FIREBASE_AUTH_DOMAIN=আপনার-project.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=আপনার-project-id
VITE_FIREBASE_STORAGE_BUCKET=আপনার-project.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=...
VITE_FIREBASE_APP_ID=...
```

## ৩. লোকালি চালানো
```bash
npm run dev
```
টার্মিনালে যে লিংক দেখাবে সেটা ব্রাউজারে খুলুন। প্রথমে একটা ফোন নম্বর
দিয়ে লগইন করতে হবে — Firebase আসল SMS-এ ৬ সংখ্যার কোড পাঠাবে সেই
নম্বরে। এরপর "পাইকারি" হিসেবে একটা ব্রাউজারে পণ্য যোগ করে, "দোকানদার"
হিসেবে আরেকটা ব্রাউজার/ইনকগনিটো ট্যাবে (আলাদা ফোন নম্বর দিয়ে লগইন
করে) সেই পণ্য দেখে অর্ডার করে টেস্ট করতে পারবেন — ডেটা Firebase-এ
সত্যিই জমা থাকবে, এবং একই নম্বর দিয়ে অন্য যেকোনো ডিভাইস থেকে লগইন
করলে নিজের আগের প্রোফাইল-পণ্য-অর্ডার ফিরে পাওয়া যাবে।

**টেস্ট করার সময় real SMS বিল এড়াতে চাইলে:** Firebase কনসোলের
Authentication → Sign-in method → Phone → নিচে **Phone numbers for
testing** সেকশনে একটা টেস্ট নম্বর ও ফিক্সড কোড (যেমন `123456`) যোগ
করে নিন — তাহলে আসল SMS ছাড়াই টেস্ট করা যাবে।

## ৪. ওয়েবসাইট হিসেবে পাবলিশ করা (Vercel/Netlify)
```bash
npm run build
```
`dist/` ফোল্ডারটা Vercel বা Netlify-তে ডিপ্লয় করুন। **গুরুত্বপূর্ণ:**
Vercel/Netlify-এর ড্যাশবোর্ডে **Environment Variables** সেকশনে গিয়ে
`.env` ফাইলের ৬টা মান একইভাবে যোগ করে দিতে হবে, নাহলে লাইভ সাইটে
Firebase কানেক্ট হবে না।

## এখন কীভাবে কাজ করে (ডেটা স্ট্রাকচার)

- **`profiles/{uid}`** — প্রতিটা ব্যবহারকারীর ভেরিফিকেশন ফর্ম/প্রোফাইল
- **`products`** — সব পাইকারির পণ্য একসাথে; প্রতিটায় `ownerId` লেখা থাকে
  কে যোগ করেছে
- **`orders`** — দোকানদারদের সব অর্ডার; `buyerId` ও `items` (প্রতিটা
  আইটেমে কোন পাইকারির পণ্য তা বোঝাতে `ownerId` সহ) থাকে

ব্যবহারকারী শনাক্ত হয় **ফোন নম্বর OTP লগইন** দিয়ে — Firebase আসল SMS
পাঠিয়ে যাচাই করে, এবং প্রতিটা ফোন নম্বরকে একটা স্থায়ী পরিচয় (uid) দেয়।
যেকোনো ডিভাইস থেকে একই নম্বর দিয়ে লগইন করলে তার প্রোফাইল-পণ্য-অর্ডার
ফিরে পাওয়া যাবে। প্রোফাইল/অ্যাকাউন্ট ট্যাব থেকে "লগআউট করুন" চেপে
লগআউট করা যাবে।

## ৭. ফোনে "রিয়েল অ্যাপ" হিসেবে ইনস্টল করা (PWA — Play Store ছাড়াই)

ওয়েবসাইট Vercel/Netlify-তে লাইভ হয়ে গেলে, এখন এটা ইনস্টলযোগ্য
(Progressive Web App)। মোবাইল থেকে:

**Android (Chrome):**
লাইভ লিংক খুলুন → উপরে ডানে ⋮ মেনু → **"Add to Home screen"** /
**"Install app"** চাপুন। হোম স্ক্রিনে আইকনসহ একটা পূর্ণ অ্যাপ যুক্ত
হয়ে যাবে — ব্রাউজারের অ্যাড্রেস বার ছাড়াই খুলবে, ঠিক নেটিভ অ্যাপের মতো।

**iPhone (Safari):**
লাইভ লিংক খুলুন → নিচে **Share (শেয়ার)** আইকন → **"Add to Home Screen"**
চাপুন।

এর জন্য প্রজেক্টে যা যোগ করা হয়েছে:
- `public/manifest.webmanifest` — অ্যাপের নাম, আইকন, থিম কালার
- `public/icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — হোম
  স্ক্রিন আইকন (চাইলে নিজের লোগো দিয়ে এই ফাইলগুলো বদলে দিতে পারবেন)
- `public/sw.js` — সার্ভিস ওয়ার্কার, যেটা অ্যাপটাকে ইনস্টলযোগ্য করে ও
  ইন্টারনেট না থাকলেও অ্যাপ-শেল খোলা রাখে

**লক্ষ্য রাখবেন:** PWA ইনস্টল প্রম্পট কাজ করতে ওয়েবসাইট অবশ্যই
**HTTPS**-এ হোস্ট হতে হবে (Vercel/Netlify এমনিতেই HTTPS দেয়, তাই আলাদা
করে কিছু করতে হবে না)। শুধু লোকাল `npm run dev`-এ (http) থেকে ইনস্টল
প্রম্পট নাও আসতে পারে — লাইভ লিংকে টেস্ট করুন।

## পরের ধাপে যা যোগ করা যাবে
- **খাতা (বাকির হিসাব)** — এখনো এটা শুধু প্লেসহোল্ডার, Firestore-এ
  connect করা হয়নি
- **অ্যাডমিন প্যানেল** — পাইকারিদের ভেরিফিকেশন ডকুমেন্ট যাচাই করার জন্য
- **ছবি আপলোড** — এখন পণ্যের/দোকানের ছবি আসলে সেভ হয় না, শুধু আইকন
  দেখানো হয়; Firebase Storage যোগ করলে আসল ছবি আপলোড করা যাবে

এই কাজগুলো করতে চাইলে বলবেন, একে একে যোগ করে দেব।
